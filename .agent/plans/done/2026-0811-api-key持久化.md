## 关键上下文
当前 `SessionSecretStore` 仅在 actor 内存中保存字符串，应用退出即丢失。用户明确指定将凭据保存在应用数据中，不使用 macOS Keychain。该方案实现简单，但本地配置可被同一用户读取；实现需避免在错误与日志中泄露密钥内容。
