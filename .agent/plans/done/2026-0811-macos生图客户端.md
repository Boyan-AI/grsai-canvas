## 关键上下文
- 参考站点 `https://image.grsai.ai/` 当前公开页面是响应式双栏工作台：左侧结果网格，右侧上传、模型、尺寸、提示词与生成按钮，顶部提供获取/设置 API Key。
- 当前仓库是 Grsai Python CLI/Skill，不是 macOS 工程；现有代码是接口语义、安全边界与测试用例的参考实现，不把 Python 运行时嵌入 App。
- 原生接口为 `POST /v1/api/generate` 与 `GET /v1/api/result?id=...`；结果地址和上游地址仅允许 HTTPS。
- MVP 不包含账号体系、云同步、批量并发队列、图片编辑器、签名公证、自动更新和 Mac App Store 发布，避免范围失控。
- CodeGraph 未初始化；如用户批准，可在实质开发前单独初始化索引，否则继续使用结构化 Swift 代码组织与定向只读探查。
- `generated-images/` 与 `outputs/` 当前为未跟踪用户内容，不修改、不删除、不提交。
- 执行每一步前必须检查本文件对应 Step 下是否出现 `// BY` 用户批注并逐条遵守。
